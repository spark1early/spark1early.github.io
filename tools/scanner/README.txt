S1EL POOL SCANNER — installable web app (PWA)

HOST IT (pick one):
- GitHub Pages: drop this whole "scanner" folder into your repo, e.g.
  spark1early.github.io/tools/scanner/  -> open that URL on your phone.
- Netlify: drag this folder into a new Netlify site (same as BIFF).

INSTALL TO HOME SCREEN:
- iPhone (Safari): open the URL -> Share -> "Add to Home Screen".
- Android (Chrome): open the URL -> tap the "Install" bar, or menu -> "Install app".

Must be served over https (GitHub Pages and Netlify both are). Opening the
file directly from storage will not register the app or load live data.
